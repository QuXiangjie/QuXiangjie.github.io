Agent Isolation Layers

Going from a single process up to a microVM, one layer at a time. Each layer stops some problems and not others. The page is built around one setup: a container running several claude subprocesses. Source: Hosting the Agent SDK and anthropics/sandbox-runtime.

Reference

Glossary

Running things
process
A running program, with its own memory and a PID.Your FastAPI app is one.
subprocess
A process started by another process.query() starts a claude subprocess.
process tree
Parents and children: app → claude → bash → git.One session = one branch of the tree.
stdio
The stdin/stdout pipes between a parent and its child.How the SDK talks to claude. No network port.
cwd
Working directory: the folder a process treats as "here."Just a starting point. cd .. still works.
Limiting things
sandbox
Any setup that runs code with restricted access. A goal, not a product.
namespace
Linux feature that gives a process its own view of something (files, network, PIDs).
cgroup
Linux feature that caps how much CPU and RAM a group of processes can use.
seccomp
Linux feature that blocks specific system calls.
container / image
Namespaces + cgroups + a packaged filesystem. The image is the template; the container is a running copy of it.Shares the host kernel.
gVisor · Firecracker · VM
gVisor intercepts system calls with a kernel written in user space. Firecracker and VMs boot their own guest kernel.
Agent-hosting words
srt (sandbox-runtime)
Fences one command and all its children: limits on writes, reads and network. Uses bubblewrap on Linux and Seatbelt on macOS.Writes and network denied by default; reads allowed by default.
egress / proxy
Egress is outbound traffic. A proxy is the middleman that checks every request against an allowlist.
multi-tenant
One container or host serving several users ("tenants").
ephemeral
Thrown away when stopped. Container disk is ephemeral by default.
SessionStore
SDK adapter that copies transcripts to durable storage.Transcripts only, not CLAUDE.md or artifacts.
